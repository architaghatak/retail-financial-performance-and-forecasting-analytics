# Retail Financial Performance & Forecasting Analytics

End-to-end business intelligence project analyzing retail financial performance using SQL, Python forecasting models and Power BI dashboards.

## Tools & Technologies
- SQL (MySQL) – Data cleaning, transformation and aggregation
- Python (Pandas, Statsmodels) – Time-series forecasting using SARIMA and Holt-Winters
- Power BI – Interactive dashboards and financial performance visualization

## Project Workflow
Retail Sales Dataset  
↓  
SQL Data Cleaning & Aggregation  
↓  
Python Forecasting Models  
↓  
Power BI Dashboard & Visualization

## Key Insights
- Total revenue reached approximately $13M with stable profit margins around 11–12%.
- Profitability declines significantly when discounts exceed 40%.
- The Consumer segment contributes the largest share of total revenue.
- Standard Class shipping dominates overall order volume.

## Forecasting Results
- Projected revenue for FY2015: **$5.77M**
- Average forecast error: **~$42K (≈14–16%)**
